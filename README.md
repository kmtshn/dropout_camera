# Red Dropout Camera

帳票OCR向けに、カメラ映像から赤系の罫線・枠をリアルタイム除去するPWAです。

## 特徴
- 完全ローカル処理（アプリ自体は画像を外部送信しない）
- リアルタイムで赤系ドロップアウトを確認
- 原本 / 赤除去 / グレースケール / 二値化の表示切替
- 赤の許容範囲、最低彩度、二値化しきい値を調整可能
- 原本JPEGとOCR向けPNGを個別保存
- OCRカメラ / バーコードをタブで切り替え
- カメラ映像からバーコード / QRコードを連続検出
- 読み取り後も停止せず、最大100件まで履歴表示
- 最新1件または全件をコピー可能
- バーコード解析も端末内で実行し、読み取り値を外部送信しない
- PWA対応・オフラインキャッシュ

## 使い方
1. HTTPS環境または localhost で開く
2. 「カメラ開始」からカメラ権限を許可
3. 赤除去の強さを調整
4. バーコードを読み取る場合は「バーコード」タブへ切り替える
5. コードを順番にカメラへ向けると、停止せず連続で履歴へ追加される
6. 必要に応じて最新1件または全件をコピー
7. 帳票は「OCRカメラ」タブで「撮影」して原本またはOCR画像を保存

## ローカル起動例
Windowsの場合、フォルダ内で以下を実行します。

```powershell
python -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。

## 注意
カメラの `getUserMedia()` は通常、HTTPSまたはlocalhostでのみ利用できます。


## バーコード読み取り
対応ブラウザでは `BarcodeDetector` API を使用し、元のカメラ映像を端末内で解析します。赤ドロップアウト後の画像ではなく原映像を解析するため、OCR向け画像処理とは独立して動作します。QRコードにURLが含まれていても自動では開きません。同じコードを画面に出し続けても重複登録せず、一度画面から外して再度向けると再読取できます。
